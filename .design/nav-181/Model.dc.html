Rules the manifest carries
A section with no visible entry is not drawn — no empty header, no stray divider.
Sections keep this order at every width; ordering is the manifest's, never registration order.
A route absent from the manifest is reachable but invisible — how maintenance, municipalities and vehicle-inventory stay out without a second list.
Capability check is hasPermission(role, action) from @redinfo/shared — the same table the backend guards with, so the menu cannot drift from it.
