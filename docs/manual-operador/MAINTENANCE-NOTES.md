# Manual maintenance notes

Internal notes for whoever edits this manual — not part of `manual.md` because that file is
meant to be read by the operator, not by whoever maintains the document or the system.

- The screenshots in `images/` are generated by the `capture-screenshots.mjs` script in
  this same folder — re-run it whenever the app's look changes, instead of taking
  screenshots by hand.
- After editing `manual.md`, generate the PDF with `node docs/manual-operador/generate-pdf.mjs`
  (see that file's header for prerequisites, namely `pandoc`).
